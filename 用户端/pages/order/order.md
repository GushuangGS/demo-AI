# 小程序订单tab模块工作计划

## 项目背景

小程序“Urban Architect”包含订单相关三个核心页面：

- 待接单订单页
- 进行中订单页
- 我的订单页（含全部/进行中/待评价/已完成）

目标：实现订单状态区分、信息展示清晰、操作路径统一。

---

## 一、页面功能梳理

### 1. 待接单订单页

**状态特征**：用户已下单，系统派送中，尚未有骑手接单  
**关键元素**：

- 预计接单时间（如“预计3分钟内接单”）
- 订单编号
- 预估价格
- 取件地址 / 收件地址
- 操作按钮：修改备注、联系客服、取消订单

**开发要点**：

- 倒计时或提示文案动态更新
- 取消订单需二次确认
- 联系客服跳转客服页面

---

### 2. 进行中订单页

**状态特征**：骑手已接单并取货，正在配送  
**关键元素**：

- 预计送达时间
- 骑手信息（姓名、评分、完成单量）
- 配送进度文案（如“骑手已取货，正火速赶往您的地址”）
- 送达地址 + 收货人联系方式
- 订单号、支付方式
- 物品详情（名称 + 数量）
- 联系客服中心

**开发要点**：

- 配送进度可设计为步骤条或时间线
- 支持地图查看骑手位置（可后续迭代）
- 完成配送后自动跳转评价或订单详情

---

### 3. 我的订单页

**状态分类**：全部 / 进行中 / 待评价 / 已完成  
**卡片信息**：

- 项目名称 + 订单号
- 设计内容简介
- 价格
- 操作按钮（查看详情、联系建筑师、评价订单、再次咨询等）

**开发要点**：

- 按状态切换列表
- 待评价订单需突出评价入口
- 已完成订单支持再次咨询或查看详情
- 底部导航：预约 / 订单 / 我的

---

## 二、页面与状态对应关系

| 页面             | 订单状态 | 用户操作权限                         |
| ---------------- | -------- | ------------------------------------ |
| 待接单订单页     | 待接单   | 修改备注、取消订单、联系客服         |
| 进行中订单页     | 配送中   | 查看进度、联系客服、查看物品详情     |
| 我的订单（全部） | 所有状态 | 按状态筛选、查看详情、评价、再次咨询 |
