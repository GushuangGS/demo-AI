# 任务计划

## 目标

- 为 `用户端/pages/mine/mine.vue` 增加未登录态微信授权登录流程。
- 登录成功后切换为已登录态页面，并按 `用户端/file/我的/screen的副本.png` 1:1 还原优化样式。

## 阶段

- [complete] 1. 检查当前“我的”页、项目登录能力与设计稿参考
- [complete] 2. 设计登录态数据结构与本地持久化方案
- [complete] 3. 实现未登录态点击触发微信授权登录
- [complete] 4. 实现已登录态页面结构与样式还原

## 决策

- 当前仓库未发现后端登录接口，优先实现微信授权登录调用与本地登录态存储。
- 登录态页面与未登录态页面保留在同一页面内，通过状态切换渲染。

## 风险

- 若运行环境不是微信小程序，`uni.getUserProfile` / `uni.login` 需要降级提示。
- 当前登录为前端本地持久化方案，若后续接入后端，需要将 `code` 发送到服务端换取真实会话。
