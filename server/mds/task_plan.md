# 任务计划

## 目标

- 将项目中 `material-symbols-outlined` 等图标替换为本地 PNG 图标资源。
- 将所有需要的图标下载并保存到 `用户端/static/icons`。
- 使用统一组件引用本地图标，尽量减少手工逐页修改成本。
- 保证替换后页面无新增语法错误。

## 阶段

| 阶段 | 状态     | 内容                                 |
| ---- | -------- | ------------------------------------ |
| 1    | complete | 扫描项目图标使用点与图标名称         |
| 2    | complete | 批量下载图标 PNG 到本地 static 目录  |
| 3    | complete | 将页面中的图标渲染替换为本地图标组件 |
| 4    | complete | 诊断检查与收尾                       |

## 风险与注意

- 项目中既有静态图标文本，也有 `item.icon` / `item.bgIcon` 动态图标名，需要统一兼容。
- `uni.showToast({ icon: 'none' | 'success' })` 这类不是页面图标资源，不应误替换。
- 需要尽量保留现有颜色、大小和布局表现。
